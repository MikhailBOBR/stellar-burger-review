# Stellar Burger - Проектная работа 11-го спринта

## Описание проекта
Данный проект представляет собой веб-приложение для космической бургерной "Stellar Burger", разработанное в рамках учебного курса Яндекс Практикума. Приложение позволяет пользователям создавать и заказывать космические бургеры с различными ингредиентами, отслеживать историю заказов и управлять своим профилем.

## Функциональность
- Конструктор бургеров с drag-and-drop интерфейсом
- Оформление и отслеживание заказов
- Личный кабинет пользователя
- История заказов с детальной информацией
- Защищенные маршруты и авторизация

## Используемые технологии
- **Сreate React App** — для быстрого и удобного старта разработки проекта, обеспечивает готовую конфигурацию webpack и babel
- **Redux Toolkit** — эффективное управление состоянием приложения с минимальным шаблонным кодом
- **React Router v6** — маршрутизация с полной системой авторизации:
  - Регистрация новых пользователей
  - Авторизация существующих пользователей
  - Восстановление и сброс пароля
  - Редактирование профиля пользователя
- **Хранение токенов в cookie** — надёжный и удобный способ авторизации с автоматическим обновлением
- **Защищённые маршруты** — ограничение доступа к страницам без авторизации с помощью компонентов-обёрток
- **TypeScript** — строгая типизация компонентов и утилит для повышения надёжности и предотвращения ошибок
- **WebSocket** — для получения обновлений о заказах в реальном времени
- **Jest** — тестирование бизнес-логики с помощью тестов всех редьюсеров
- **Cypress** — функциональное тестирование пользовательских сценариев

## Структура проекта
- `/src/components` — React-компоненты
- `/src/pages` — компоненты страниц
- `/src/services` — Redux-логика (слайсы, редьюсеры, экшены)
- `/src/utils` — вспомогательные функции и константы
- `/src/hooks` — пользовательские хуки
- `/src/types` — TypeScript типы и интерфейсы

## Установка и запуск проекта
1. Клонировать репозиторий: `git clone <URL репозитория>`
2. Установить зависимости: `npm i`
3. Запустить проект в режиме разработки: `npm start`
4. Для сборки проекта: `npm run build`
5. Для запуска тестов: `npm test`
6. Для запуска Cypress-тестов: `npm run cypress`
